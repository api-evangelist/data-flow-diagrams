# Data Flow Diagrams (data-flow-diagrams)

Data Flow Diagrams (DFDs) are graphical models that depict how data moves through a system across processes, data stores, external entities, and flows. The technique spans Yourdon/DeMarco and Gane-Sarson notations, hierarchical context and level-N decomposition, and modern tooling for threat modeling, software architecture, and data governance.
